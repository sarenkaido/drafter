# Changelog

## 1.3.0

- Welcome screen on first run: pick your language, calendar and currency
- The calendar is now independent of the language (Persian or Gregorian with either language)
- Currency picker: toman, rial, a list of world currencies, or your own label
- Amounts with cents for currencies that use them (e.g. 12.50 USD)
- Imported backup and CSV files are validated before use
- Release builds: actions pinned to exact commits, least-privilege permissions

## 1.2.0

- English interface, alongside Persian (left-to-right layout in English)
- Gregorian calendar option
- Built-in categories are shown in the chosen language

## 1.1.0

- Android and Linux versions
- Phone layout: bottom tab bar, floating add button, bottom sheets, back-button support
- Import and export work with Android's file picker

## 1.0.0

- First release for Windows: daily income and expenses, categories, charts, yearly report, CSV and JSON export/import, daily automatic backups
